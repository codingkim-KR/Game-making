검은 성전 / Motion Lab 0.5.1 — 검증 기록

실행 환경과 한계
- Godot 4.6.3.stable.official.7d41c59c4, Linux.
- 물리 처리 목표는 60Hz. 자동 검사에서 사용하는 --fixed-fps 60은 시간 간격을
  통제하기 위한 설정이며, 화면에서 60FPS를 달성했다는 뜻은 아니다.
- 이 환경에서는 Windows 또는 Wine으로 실행하지 않았다. Windows에서의
  실제 동작 및 성능은 확인하지 않았다.
- 사용 가능한 오디오 출력이 없어 사운드의 청감과 음량 균형은 확인하지 못했다.

0.5.1 자동 검사: 총 124개 통과, 실패 0개

   착지 직전 점프 입력, 공중 회피 1회 제한과 착지 회복, 벽 미끄러짐과 벽차기,
   일반검/대검/세검의 단타와 3/4/4연격, 공격별 중복 타격 방지, 무기별 피해,
   대검 차지 및 회피 취소, 공중 공격의 착지 연속성과 방향 고정, 무기 교체 예약,
   와이어 연결/거리 제한/해제 시 운동량/추가 회피 방지/와이어 공격,
   피격/피격 보호/정면 패링/회피 무적/사망/리셋, 실제 더미 타격 기록 초기화,

   옮겼다. 나머지 기존 행동 검사의 성공 기준은 유지했다.

2. 기존 실제 모델과 무기 판정 통합 회귀 검사: 13개

   세 무기 각각의 단타와 전체 연격이 왼쪽/오른쪽 양방향에서 더미에 적중했고,

   이루어진다. 헤드리스 결과만으로 모션의 시각적 완성도를 판정하지 않았다.

3. 차지·관통·절벽·구역 시작 위치 변경 검사: 48개
   tools/test_patch_v051.gd → docs/QA_patch_v051.json
   실제 hero.glb 골격, HeroVisual, 무기 소켓, 플레이어 물리를 함께 실행했다.
   - 세 무기 모두 최대 충전 이전에는 공격하지 않고 최대 충전 후 자동 발동했다.
   - 버튼을 계속 눌러도 공격이 반복되지 않았으며, 한 번의 충전에서 공격 ID는
     정확히 한 번 증가했다. 자동 발동에는 최대 충전 피해가 적용됐다.
   - 최대 충전 이전에 버튼을 놓으면 부분 충전 공격을 했고, 짧게 눌렀다 놓으면
     충전 없는 강공격을 했다.
   - 입력을 중립으로 둔 채 최대 충전 공격 후 실제 전진 거리를 측정했다.
     일반검 0.50m, 대검 0.65m, 세검 2.80m였다. 이 값은 게임 세계 단위이다.
   - 세검은 전방 세 표적에 각 한 번만 피해를 주었고, 세 표적 모두 동일한 공격
     ID를 기록했다. 왼쪽을 바라보는 경우에도 왼쪽으로 돌진했다.
   - 고체 벽 앞에서 세검 돌진이 멈췄으며, 벽 너머 표적에는 피해를 주지 않았다.
   - 양방향 절벽에서 실제 지형을 통해 매달림에 진입했다. 접근할 때부터 누르던
     방향키를 2초 계속 누르거나 키를 놓고 2초 기다려도 자동으로 올라가지 않았다.
   - 매달린 동안 플레이어 위치는 고정됐고, 양손 본 위치가 반복 애니메이션처럼
     순환하지 않았다. 양손이 절벽 끝에 닿는 위치도 검사했다.
   - 방향키를 놓았다가 벽 쪽으로 다시 누르면 올라서기가 시작됐다. W/위 방향키도
     올라서기를 시작했다. 양쪽 방향에서 3m 높이 플랫폼 위에 안정적으로 착지했다.
   - 아래 입력으로 절벽을 놓고 떨어지는 기존 동작도 유지됐다.
   - 실제 연습장 4개 구역 시작 위치에 플레이어와 같은 높이 1.78m·반경 0.24m
     캡슐을 배치한 물리 교차 검사에서 지형과 겹치는 위치가 없었다. F2 시작
     위치는 발판과 벽 사이의 빈 공간으로 옮겨, 작은 발판과의 겹침을 없앴다.
   - 마지막 손 위치 및 올라서기 자세 보정 이후 위 48개와 실제 무기 통합 13개
     검사를 다시 실행하여 모두 통과했다.

검사 중 수정 후 재검증한 기존 문제
- 지상에서 공중으로 리셋 직후 직전 지상 접촉 정보가 남아 공중 공격이 지상
  공격으로 분류되는 0.5의 문제 수정은 0.5.1에서도 회귀 검사로 유지했다.

이전 0.5에서 네이티브 화면으로 확인한 항목
- 캐릭터 모델 표시와 실제 입력에 따른 이동 및 공격.
- 일반검 2회 타격 36 피해, 세검 1회 타격 11 피해와 더미 피격 표시.
- 벽차기, 와이어 연결 선과 한 손 지지 자세, 4개 테스트 구역 전환.
- 와이어 구역 카메라 조정 후 두 고리가 상단 UI 아래에 보임.
- 소프트웨어 Mesa 렌더러에서 약 21–28FPS 관측. 일반 PC의 GPU 성능이나
  60FPS 보장을 대표하지 않는다.
위 항목은 이전 0.5의 관찰 기록이다. 0.5.1의 새 모션 화면 확인은 별도로 기록한다.

자동 검사 재현 명령
프로젝트 폴더에서 다음 명령을 실행한다.
godot --headless --path . --fixed-fps 60 --script res://tools/test_lab.gd
godot --headless --path . --fixed-fps 60 --script res://tools/test_live_collision.gd
godot --headless --path . --fixed-fps 60 --script res://tools/test_patch_v051.gd

검증 범위
이 결과물은 이동/전투/전환을 직접 시험하는 실험실이다. 완성된 본편, 적 AI,
장시간 플레이 밸런스, 모든 하드웨어 조합의 성능을 검증한 결과물이 아니다.
Windows 배포물의 압축 무결성과 PE x86_64 형식 검사는 패키징 과정에서 수행하며,
해당 결과는 배포 manifest에 기록한다. Windows 실행 검증과는 다르다.

최종 v0.5.1 네이티브 화면 확인

- F2의 수정된 시작 위치에서 오른쪽+점프로 턱을 잡았고, 입력이 없는 동안 양손 고정·무기 숨김·매달림 유지가 보였습니다.
- W 입력 후 상체를 먼저 당겨 올리는 중간 자세와 절벽 위에 올라선 최종 상태를 확인했습니다.
- 0.5배속에서 최종 등반 표현을 확인했고, 확장된 조작 안내가 화면 안에 들어오는 것을 확인했습니다.
- Windows 직접 실행과 오디오 청감은 이번에도 수행하지 않았습니다.
