검은 성전 · 전환 모션 테스트 v0.5.1

실행
Windows ZIP을 압축 해제한 뒤 BlackCrusadeMotionLab_v05.exe를 실행합니다.
별도 설치, 로그인, 인터넷 연결은 필요하지 않습니다. Windows x86_64용입니다.
소스 ZIP은 Godot 4.6.3에서 project.godot를 가져온 뒤 F6이 아니라 F5로 실행합니다.

이번 프로그램의 범위
일반검·대검·세검을 바꾸면서 이동/점프/전투가 이어지는 감각을 확인하는 연습장입니다.
이전 v0.4의 스킨 캐릭터와 골격을 사용하고, 쌍검은 세검으로 교체했습니다.
영상 재생 대신 실제 입력·물리·무기 소켓에 애니메이션과 충돌을 연결했습니다.
39개 원본 골격 클립에 전환 보간, 상하체 혼합, 손 위치 보정을 적용했습니다.
설계 문서의 186개 항목을 모두 별도 완성 애니메이션으로 제작한 버전은 아닙니다.
스토리, 적 AI 캠페인, 육성, 저장 기능은 이번 테스트 범위에 포함하지 않았습니다.

조작
A / D 또는 좌우 방향키 : 달리기
Shift + 이동 : 걷기
Space : 점프 / 벽차기 / 공중에서 와이어 놓기
J 또는 마우스 왼쪽 : 약공격 연계 (다음 타격은 다시 입력)
L 또는 마우스 오른쪽 : 차지 완료 시 자동 공격. 일찍 놓으면 그때 발동합니다.
W + 공격 : 공중 상단 공격
S + 공격 : 낙하 공격
K 또는 Ctrl : 회피
I : 방어, 누른 직후의 짧은 구간은 패링
E : 가까운 고리에 와이어 연결 / 해제
턱 매달리기 : 입력 없이 유지. 벽 쪽 방향키를 다시 누르거나 W / ↑로 올라서기
매달린 상태 S / ↓ : 손 놓기. 반대 방향 + Space : 벽에서 뛰어내리기
1 / 2 / 3 : 일반검 / 대검 / 세검
R : 현재 구역과 더미, 체력 초기화
H 또는 Esc : 조작 안내 및 일시정지
F1 / F2 / F3 / F4 : 기본 전투 / 벽 이동 / 와이어 / 방어 훈련
F5 : 0.5배속
F6 : 검 궤적·캐릭터 판정 참고선과 FPS 표시
T : 공격 더미 켜기 / 끄기
M : 음소거
F11 : 전체 화면

먼저 해 보실 순서
1. F1에서 1·2·3번 무기를 바꿔 더미 앞에서 연속으로 J를 누릅니다.
   일반검 3타, 대검 4타, 세검 4타이며 대검은 발을 딛고 공격합니다.
2. Shift로 걸으며 공격한 뒤, 달리다가 반대로 움직이고 점프 중에도 방향을 바꿉니다.
   일반검과 세검의 가벼운 공격은 하체 이동을 유지합니다.
3. 공중에서 공격한 채 착지하고, 다시 이동·회피·공격을 연결합니다.
4. 세검을 들고 세 표적 앞에서 L을 계속 누릅니다. 차지가 끝나면 자동 돌진하며 여러 표적을 관통합니다.
   일반검/대검도 차지가 끝나면 자동 공격하며 조금 전진합니다. 버튼을 계속 눌러도 재발동하지 않습니다.
5. F2에서 오른쪽 + Space로 벽의 턱을 잡습니다. 턱을 잡은 뒤 아무 키도 누르지 않고 기다립니다.
   벽 쪽 방향키를 놓았다 다시 누르거나 W / ↑를 누르면 손으로 당겨 올라섭니다.
6. F3에서 E로 줄을 연결하고 점프해 이동합니다. 공중 J와 L을 비교합니다.
   일반검/세검은 줄을 유지하며 약공격, 대검은 강공격으로 줄을 놓은 뒤 공격합니다.
7. F4에서 T를 켜고 접근합니다. 예고 표시를 보고 I로 방어·패링하거나 K로 회피합니다.

표현과 테스트 기능
캐릭터를 화면 높이 약 1/4 수준으로 배치했습니다. 와이어 구역은 고리가 보이도록 조금 넓게 보입니다.
화면을 저해상도로 줄였다 늘리는 후처리를 쓰지 않고, 원래 해상도에서 단순한 명암으로 렌더링합니다.
완성된 수작업 도트 에셋은 아닙니다. 현재 목표는 모션·전환·타격감 검토입니다.
검 전체를 복제한 잔상 대신 타격 구간의 검끝 궤적을 짧게 표시합니다.
더미는 적중 시 상체 반동·압축·섬광·파편·피해 숫자로 반응합니다.
물리는 초당 60회, 렌더링 상한은 60FPS이며 실제 FPS는 하드웨어에 따라 달라집니다.

v0.5.1 변경점
- 최대 차지 시간에 도달하면 자동 공격하며, 입력을 놓고 다시 누르기 전에는 반복되지 않습니다.
- 세검의 차지 공격은 전방 관통 돌진입니다. 적은 관통하지만 벽과 지형은 통과하지 않습니다.
- 일반검과 대검의 차지 공격은 타격에 맞춰 조금 전진합니다.
- 턱에 매달린 채 대기하고, 새로 입력했을 때 당겨 올라서는 동작으로 연결합니다.
- F1 연습장에 관통 확인용 표적 세 개를 일렬로 배치했습니다.

검증 범위
실제 Godot 물리/컨트롤러 63개, 골격·무기 소켓·충돌 통합 13개, 이번 변경·시작 위치 검사 48개, 총 124개를 통과했습니다.
Linux 네이티브 창에서 세검 자동 차지의 세 표적 관통, 매달림 유지, 위쪽 입력 후 당겨 올라서는 중간 자세와 최종 착지를 직접 확인했습니다.
Windows 실행 파일은 내보내기와 파일 구조를 검사했으며, Windows에서 직접 실행하지는 못했습니다.
현재 시험 환경은 소프트웨어 그래픽 드라이버입니다. 최종 사용 PC의 60FPS 성능을 보장하지 않습니다.
효과음 파일과 호출은 포함했으나 시험 환경에 오디오 출력 장치가 없어 청감 검증은 하지 못했습니다.
자세한 결과는 docs/QA.txt에 있습니다.
